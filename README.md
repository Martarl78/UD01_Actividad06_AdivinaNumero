# 🎯 Adivina el Número

## 📖 Descripción

**Adivina el Número** es un pequeño juego de consola desarrollado en **Kotlin**. El programa genera un número secreto aleatorio entre **1 y 100** y el jugador debe descubrirlo con la ayuda de pistas ("mayor" o "menor") tras cada intento.

El juego no termina hasta que se acierta, y al final muestra cuántos intentos válidos se han necesitado.

## ✨ Características

- 🎲 **Número aleatorio** entre 1 y 100 en cada partida.
- 💡 **Pistas** después de cada intento: el número secreto es *mayor* o *menor*.
- 🛡️ **Validación de entradas**:
  - Texto o caracteres no numéricos.
  - Números fuera del rango permitido (1–100).
  - Entradas vacías o con espacios.
- 🔢 **Contador de intentos**: solo cuentan los intentos válidos.
- 🔁 **Bucle de juego** hasta acertar.
